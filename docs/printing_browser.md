# การพิมพ์ผ่านเบราว์เซอร์สำหรับเครื่องพิมพ์ 80 มม.

เอกสารนี้สรุปวิธีใช้งานปุ่ม **“พิมพ์ (เบราว์เซอร์)”** ใน MyDent เวอร์ชันเว็บ รวมถึงการตั้งค่าไดรเวอร์เพื่อให้ภาพและตัวหนังสือคมชัด พร้อมวิธีเปิดฟังก์ชันตัดกระดาษอัตโนมัติสำหรับเครื่องพิมพ์ความร้อนยอดนิยม

## ขั้นตอนการใช้งาน

1. เปิดหน้าพรีวิวใบเสร็จ ใบนัด หรือสลิปรวม แล้วคลิกไอคอนเครื่องพิมพ์
2. เลือกเมนู **“พิมพ์ (เบราว์เซอร์)”**
   - หากตั้งค่าโหมด PNG: ระบบจะส่งภาพความกว้าง 80 มม. ไปยังหน้าต่างใหม่เพื่อพิมพ์ทันที
   - หากตั้งค่าโหมด HTML: ระบบจะเรนเดอร์ HTML+CSS ในหน้าต่างใหม่ ตัวหนังสือจะคมชัดกว่าการพิมพ์แบบภาพ
3. ตรวจสอบว่า Chrome/Edge แสดงตัวอย่างหน้ากระดาษที่กว้าง 80 มม. โดยไม่มีระยะขอบ (Scale = 100%) แล้วสั่งพิมพ์
4. ถ้าเปิดตัวเลือก **ปิดหน้าต่างอัตโนมัติ** ไว้ หน้าต่างพิมพ์จะปิดเองเมื่อคำสั่งถูกส่งไปยังเครื่องพิมพ์

> **หมายเหตุ:** ทุกครั้งที่เปลี่ยนค่าในหน้า *Dev → โปรไฟล์พิมพ์ (Browser)* ให้รีเฟรชหน้าพรีวิวก่อนสั่งพิมพ์อีกครั้ง

## การตั้งค่า CSS ที่หน้า `print/print.html`

หน้า HTML ถูกออกแบบให้พิมพ์ด้วยความกว้าง 80 มม. ตรงตามหน้ากระดาษโดยไม่สเกลอัตโนมัติ โดยตั้งค่าหลัก ๆ ดังนี้

```css
@page { size: 80mm auto; margin: 0; }
html, body { margin: 0; padding: 0; background: #fff; }
img { width: 80mm; height: auto; image-rendering: pixelated; }
```

สำหรับโหมด HTML มีการกำหนดฟอนต์ fallback เช่น `"Noto Sans Thai"`, `"Sarabun"`, `"Tahoma"` พร้อม `line-height` 1.3 เพื่อให้ภาษาไทยอ่านง่ายและคงรูปแบบเมื่อพิมพ์จริง

## ตั้งค่า Auto Cut ในไดรเวอร์ยอดนิยม

### Epson TM Series (TM-T82/TM-T88)
1. เปิด **Printer Properties** → แท็บ **Device Settings**
2. คลิก **Printing Preferences…**
3. ตั้งค่า `Roll Paper Width` เป็น 80 mm และเลือก **Auto Cut** เป็น `Cut at end`
4. ในแท็บ **Advanced** เปิด **Enable Advanced Printing Features** แล้วกดบันทึก

### XPrinter รุ่น XP-Q80 / XP-S300
1. เปิด **Printing Preferences** → แท็บ **Device Setting**
2. กำหนด `Paper Width` = 80 mm และ `Print Density` ตามที่ต้องการ
3. เปิด **Cutter Control** และเลือก `Partial Cut` หรือ `Cut After Printing`
4. กด Apply แล้ว OK

### Rongta RP80 / RP850
1. เปิด **Printing Preferences** → แท็บ **Page Setup**
2. ตั้งค่า `Paper Width` = 80 mm, `Margins` = 0
3. ไปที่แท็บ **Device Settings** แล้วติ๊ก **Auto Cutter** → `Cut at end`
4. กด Apply

หากเครื่องพิมพ์ไม่ตัดกระดาษ อาจต้องปิด-เปิดเครื่องหนึ่งครั้งหลังตั้งค่าไดรเวอร์ใหม่

## เทคนิคเพื่อความคมชัดสูงสุด

- เรนเดอร์ PNG ที่ความกว้าง 576 px (ค่าเริ่มต้น) หากเครื่องรองรับ 640 px สามารถตั้งในหน้าตั้งค่า Dev ได้
- ปิดพื้นหลังโปร่งใส ให้ใช้พื้นหลังขาวล้วนเพื่อลดแถบเทา
- กำหนดความหนาของเส้นไม่น้อยกว่า 2 px เมื่อออกแบบเทมเพลต
- ตั้งขนาดตัวหนังสือหลัก ≥ 18 px สำหรับหัวข้อ และ ≥ 14 px สำหรับรายละเอียดทั่วไป
- ใช้โลโก้ PNG ความละเอียดสูง (อย่างน้อย 400 px) เพื่อให้ไม่แตกเมื่อสั่งพิมพ์

## ปุ่ม Dev: โปรไฟล์พิมพ์ (Browser)

เปิดเมนู **Dev → ตั้งค่าโปรไฟล์พิมพ์ (Browser)** เพื่อปรับแต่งค่าเหล่านี้และบันทึกใน SharedPreferences / localStorage

- เลือกความกว้างด็อต 512 / 576 / 640 px
- สลับโหมด PNG หรือ HTML ได้ตามความต้องการ
- เปิด/ปิดการปิดหน้าต่างพิมพ์อัตโนมัติ

หลังจากบันทึกค่าแล้ว ค่าจะถูกใช้ทันทีโดยปุ่ม “พิมพ์ (เบราว์เซอร์)” ในทุกหน้าพรีวิว

## สรุป Acceptance Criteria

- เปิดหน้าพรีวิวแล้วเลือก “พิมพ์ (เบราว์เซอร์)” → Print Preview ต้องกว้าง 80 มม. และไม่มีขอบ
- ภาพ/ตัวหนังสือคมกว่าวิธี ESC/POS เดิมเมื่อพิมพ์บนเครื่องรุ่นเดียวกัน
- เมื่อเปิด Auto Cut ในไดรเวอร์ เครื่องพิมพ์จะตัดกระดาษหลังพิมพ์เสร็จ
- ปุ่ม QZ / ESC-POS เดิมยังใช้งานได้ตามปกติ
